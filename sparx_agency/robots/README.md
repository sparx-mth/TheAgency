# Robots

This folder contains code for interacting with specific platforms.

1. [XTEND](./XTEND/README.md)
2. [ROBOTICAN](./ROBOTICAN/README.md)
3. [ASGARD](./ASGARD/README.md) — REST client for the external Unity swarm simulator
4. [PEGASUS](./PEGASUS/README.md) — simulated drone: Isaac Sim + Pegasus Simulator + PX4 SITL
5. [SJTU](./SJTU/README.md) — simulated velocity-controlled drone in ROS 2 Humble + Gazebo Classic, driven from an external `$SJTU_PROJECT_DIR` checkout
