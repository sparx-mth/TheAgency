# Planning Package

The planning package provides path planning and trajectory generation capabilities for autonomous agents in The Agency
project. It handles both single-agent and multi-agent planning scenarios in unknown or partially known environments.

## Key Features

- Multi-agent path planning with collision avoidance
- Dynamic replanning based on environmental changes
- Support for various cost functions and constraints
- Integration with mapping and localization modules
- Real-time trajectory generation

## Core Components

- Global Planner: Handles high-level path planning
- Local Planner: Manages reactive obstacle avoidance
- Trajectory Generator: Converts paths into executable trajectories
- Constraint Manager: Enforces kinematic and dynamic constraints
