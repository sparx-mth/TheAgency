# SPARX Demos

The `demos` folder contains example scenarios and demonstrations showcasing the integration of SPARX capabilities with
tasks, sensors, and robots.


## Usage

Each demo is self-contained and includes:

- Setup instructions
- Required hardware/software components
- Step-by-step execution guide
- Expected outcomes

## Available Demos

Documentation for specific demos will be added as they are implemented.

Note: These demos are intended for testing and validation purposes, serving as templates for building more complex
applications.

*   Demo No 1 -  VLM on the edge. VLM and LLM inference on edge device
*   Demo No 2 -  VLM on rooster. Integrate 1st demo code with ROBOTICAN ROOSTER. 
    Replace rotating camera with a rotating rooster and use rooster video stream.
