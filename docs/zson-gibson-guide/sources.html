What is deliberately not on the active path?

ROS object-search/oracle nodes, generic LLM room-navigation planners, archived surveyed/hospital fixtures, old generic planning pipelines, native aerial FALCON deployments and flight trackers are not additional stages of gibson.run. The actual method construction in C01/C02 is authoritative; generic modules can contain behaviors for other callers that this benchmark never invokes.

Evidence and visual-inspection limits

Primary evidence is the actual benchmark call chain, not a generic architecture diagram. Cached PDF manifests/method/evaluation text were inspected, and the Gibson table was independently spatially isolated to prevent mixing its neighboring HM3D table. Available ApexNav/SG-Nav code entrypoints/configuration were checked against paper descriptions. The available interface could not visually display the PDF figures; attempted OCR lacked English language data. No exhaustive visual exhibit audit or external-method rerun is claimed.

The four included illustrations are a visualization derived from a real GT array, one frame decoded from an existing Shelbyville video, and copied final Shelbyville/Newfields dashboards. No new simulator trajectories were generated. Licensed meshes, full datasets, model weights, third-party code and full PDFs are not bundled.

Glossary

Terms used throughout

TermMeaning here
ObjectNav / ZSONNavigate to an acceptable object instance; zero-shot means no navigation-specific training for the stated task.
EpisodeOne start/orientation/target trial ending on STOP or its limit.
Observation / decision / actionSensor input; computation choosing behavior; an instruction executed by the simulator.
GTTruth relative to simulator/dataset. Ideal sensor GT and private scoring GT have different roles.
RGB-DColor image plus registered metric depth.
BEV / occupancyBird’s-eye map of free, occupied and unknown cells.
2.5DPlanar motion informed by a vertical obstacle slab, not full 3D navigation.
NavmeshSimulator navigation surface/connectivity used for native motion constraints.
Frontier / viewpointFree/unknown boundary; a position and viewing orientation chosen to observe it.
Room / regionInferred partition, not necessarily an architectural GT room.
LLM / VLM / VFMLanguage model; vision-language model; visual foundation model. Our room LLM consumes text, not RGB.
Affinity / probability / confidenceSemantic typicality; modeled likelihood; model/detector score. Not interchangeable or automatically calibrated.
RPT*Order search minimizing survival-weighted expected cost under a probabilistic-terminal model.
A* / Dijkstra / FMMPath/distance methods whose role depends on the caller: policy routing, room costs, semantic-graph paths or private evaluation.
CP / ATSP / SOPCoverage path; asymmetric traveling-salesperson ordering; sequential ordering with precedence.
BurstLocal exploration allocation with a persistent token and finite charged-action budget.
SR / SPL / DTGSuccess rate; successful-path efficiency; final distance to the defined success region.
TF / NMTraining-free/non-metric labels in the published table, subject to its method/controller scope.
Freeze / holdoutImmutable configuration; data not used for tuning. The former cannot retroactively create the latter.
The end-to-end mental model

See locally → build uncertain geometric/semantic memory → choose where to search → execute safe discrete motion → re-observe → stop for an explicit reason → let an independent GT evaluator judge the final outcome. The hard part is making beliefs, budgets, geometry, evidence and scoring agree throughout the loop.
